# Repository publication boundary

Release v1.3.1 publishes the reviewed architecture, scientific methods, source pins, current approved logo, diagrams, decision summaries and current PDF. Original ZIP archives, verbatim conversation records and superseded generated PDF/HTML files remain in the local delivery and are ignored by Git. Their preservation is recorded in the local archive inventory. This changes packaging, not research scope.

The supplied v1.3 folder remains untouched. Old version documents and old artwork are historical references; current entry points are README, the master TR/EN specifications, the v1.3.1 integration contract and review. No third-party checkpoints or driving runtime are distributed.

Active GitHub Actions workflows could not be published with the available OAuth credential (missing workflow scope). The current validator workflow is preserved as an inactive template in tools/ci/validate-docs.yml. Activate it through an appropriately authorized GitHub session in a future administrative step; no automated CI run is claimed here.
