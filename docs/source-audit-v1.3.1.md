The FPD scorer accepts native feature vectors; merely matching its tensor width does not establish semantic equivalence. Its NC head is named `no_at_fault_collisions`. The separate τMOTION feasibility head is additional training work. The ranking code also contains protocol-dependent DDC handling; native arithmetic is not a general calibrated safety estimator.

The stored τMOTION values 92.5/53/82/60%/0.60/1.55 are retained user-requested planning scenarios. No fitted forecasting method, τMOTION runs, or calibrated probability supports them. They must not be added to measured leaderboards. Other historical benchmark rows remain attributed upstream reports and require protocol matching before comparative scientific claims.
