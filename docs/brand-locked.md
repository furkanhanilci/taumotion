# τMOTION visual identity: user-approved purple τ is locked

The only approved *visual reference* in this archive is `assets/brand/APPROVED_PURPLE_TAU_REFERENCE_UNMODIFIED.png` (copied byte-for-byte from the prior conversation's favored architecture artwork). This reference has an elegant dark-violet tau and restrained MOTION wordmark. **Do not invent a new automobile/logo icon, distort or recolor τ, or substitute the old teal brand.**

For new scientific flow diagrams the word `τMOTION` may appear as text in a purple typographic heading, but this is **not a logo redraw**. The original v1.1 cyan/teal vector logo remains in the repository for historical compatibility only and is not asserted to be the preferred mark. To obtain an independently reusable purple vector logo, source artwork or a specific confirmed vector recreation is needed; this archive does not falsely claim that the full reference image is a clean vector logo.

Plots/flowcharts must be separate TR and EN rather than mixing the two languages in one figure; project/vendor names should not appear *inside scientific module boxes*. Source names, citation and license references remain visible in technical docs and manifests.
